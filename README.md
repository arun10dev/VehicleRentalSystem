Vehicle Rental System 🚗

A beginner-friendly, console-based Java project that displays daily rental prices for selected car brands.

Features

- Accepts a car brand from the user.
- Displays the car brand and its daily rental price.
- Checks car availability using case-insensitive string comparison.
- Displays an unavailable message for unsupported car brands.

Java Concepts Used

- Abstract classes and abstract methods
- Inheritance
- Constructors
- Method implementation and overriding
- Objects and instance variables
- "Scanner" for user input
- Conditional statements ("if-else")
- String comparison using "equalsIgnoreCase()"

Project Structure

- "Vehicle.java" — Defines the abstract "Vehicle" class and the "Car" subclass.
- "Main.java" — Accepts user input, checks availability, and displays rental details.

How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Compile "Vehicle.java" and "Main.java".
4. Run the "Main" class.
5. Enter one of the supported car brands when prompted.

Learning Outcome

This project helped me practise Java object-oriented programming concepts, especially abstraction, inheritance, constructors, and method overriding.
